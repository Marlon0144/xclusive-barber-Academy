# Traducción de UI — Panel de Administración (admin)

## Statement

The system shall renderizar todos los textos fijos de las páginas y componentes
de administración (`admin/courses/*`, `admin/gestion_users/*`, `admin/leads/*`,
`admin/lessons/[lessonId]/edit/*`, `components/admin/*`) desde el diccionario en
el idioma activo. No incluye la traducción del contenido HTML de lecciones
(fuera de alcance).

## Rationale

El panel de gestión del admin está hardcodeado en español y debe ser bilingüe.

## Acceptance Criteria

Cadenas → clave (namespace `dashboard.admin`):

- [ ] `app/dashboard/admin/courses/page.tsx`
      - `title="Administración"` → `courses.headerTitle` ("Administración"/"Administration")
- [ ] `app/dashboard/admin/courses/AdminCourseList.tsx`
      - `window.prompt('Nombre del nuevo Módulo (Ej: Corte Clásico):')` → `courses.newModulePrompt`
      - `window.confirm('¿Estás seguro de borrar este módulo y todas sus lecciones?')` → `courses.deleteModuleConfirm`
      - `window.prompt('Título de la Lección:')` → `courses.newLessonPrompt`
      - `window.confirm('¿Borrar esta lección permanentemente?')` → `courses.deleteLessonConfirm`
      - `title="Eliminar Módulo"` → `courses.deleteModule`; `title="Borrar Lección"` → `courses.deleteLesson`
- [ ] `app/dashboard/admin/courses/EditableText.tsx`
      - `title="Renombrar"` → `courses.rename`
- [ ] `app/dashboard/admin/gestion_users/page.tsx`
      - `title="Gestion de Usuarios"` → `users.headerTitle` ("Gestión de Usuarios"/"User Management")
      - "Desactivar"/"Activar" (toggle) → `users.deactivate`/`users.activate`
      - tagline "Control de acceso y roles del sistema." → `users.footerTagline`
- [ ] `app/dashboard/admin/gestion_users/CopyInviteButton.tsx`
      - "Copiado"/"Copiar" → `users.copied`/`users.copy`
- [ ] `app/dashboard/admin/leads/page.tsx`
      - `title="Gestion de Leads"` → `leads.headerTitle` ("Gestión de Leads"/"Lead Management")
      - placeholder "Buscar por nombre, email o telefono" → `leads.searchPlaceholder`
      - placeholder "Nota breve de seguimiento" → `leads.notePlaceholder`
      - Etapas y estados CRM (ver detalle) → `leads.stages.*` / `leads.statuses.*`:
        - status: "Nuevo"/"Contactado"/"Calificado"/"Perdido"/"Convertido"
        - etapas: "Etapa 1 - Curioso", "Etapa 2 - Interesado", "Etapa 3 - Muy interesado", "Etapa 4 - Cuenta creada"
        - principales (score): "Curioso"/"Interesado"/"Muy interesado"/"Cuenta creada"
      - Etiquetas de respuestas del cuestionario ("Ciudad / suburbio", "Ha cortado cabello antes", etc.) → `leads.answers.*` (las claves estables están en el archivo como `city_suburb`, `has_cut_hair_before`, `main_goal`, etc.)
      - tagline por defecto (no bloquear; verificarlo en el archivo).
- [ ] `app/dashboard/admin/lessons/[lessonId]/edit/EditLessonForm.tsx`
      - "GUARDAR"/"GUARDANDO..." → `editor.save`/`editor.saving`
- [ ] `components/admin/EditorToolbar.tsx`
      - `alert('Por favor ingresa una URL válida de YouTube')` → `editor.invalidYoutubeUrl`
      - `title` de botones: "Negrita", "Cursiva", "H1", "H2", "Lista", "Lista #", "Insertar Imagen", "Insertar Video YouTube" → `editor.toolbar.bold / italic / h1 / h2 / bulletList / orderedList / insertImage / insertVideo`
- [ ] `components/admin/RichTextEditor.tsx` y `[lessonId]/edit/page.tsx`: verificar en
      inspección; si contienen texto fijo visible, traducir bajo `dashboard.admin.editor.*`.

## Verification Method

Inspection (inventario) + Test (ES/EN en todas las pantallas admin).

## More Information

- SRS: `docs/specs/srs001.md` §3.2 (REQ-FUNC-006).
- Algunos labels CRM residen en funciones/`Record` del lado cliente (`leads/page.tsx`);
  convertirlos a lecturas del diccionario preservando los `value` estables (no
  tocar los `value` que se persisten en BD).
- El contenido HTML de lecciones dentro de `RichTextEditor` NO se traduce.
- Relacionado: REQ-010 (editar títulos `_en` desde admin) añadirá campos nuevos
  al editor de lecciones/módulos.
