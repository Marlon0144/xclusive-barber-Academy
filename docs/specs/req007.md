# Traducción de UI — Grading (Evaluación por el instructor)

## Statement

The system shall renderizar todos los textos de la sección de calificación
(`app/dashboard/grading/page.tsx`, `GradingCard.tsx`) desde el diccionario en el
idioma activo, incluyendo encabezados, estado de puntuación, mensajes de acción
y estados de carga.

## Rationale

La pantalla de calificación del instructor usa texto hardcodeado en español; debe
ser bilingüe para instructores EN.

## Acceptance Criteria

Cadenas → clave (namespace `dashboard.grading`):

- [ ] `page.tsx`
      - `title="Evaluación"` de `DashboardPageHeader` → `headerTitle` ("Evaluación"/"Grading")
      - tagline de `DashboardFooter` "Panel de evaluación — Xclusive Barber Academy." → `footerTagline`
      - Clasificadores de estado si existen en el archivo (enumerar al implementar).
- [ ] `GradingCard.tsx`
      - alt "Corte del estudiante" → `studentCutAlt`
      - Fallback "Sin descripción proporcionada." → `noDescription`
      - "CALIFICAR ENTREGA" (acción) → `submit`
      - "GUARDANDO..." (loading) → `saving`
      - Etiquetas de criterios (sliders): "Fade / Desvanecido", "Limpieza", "Técnica", "Simetría" → reutilizar `dashboard.tracker.scores.*` o definir `dashboard.grading.scores.*` (elegir UNA fuente; se recomienda compartir `scores` a nivel `dashboard`).

- [ ] Los mensajes de error de la Server Action ya usan `dictionary.actions.grading`;
      reutilizar, no duplicar.

## Verification Method

Inspection (inventario) + Test (ES/EN en flujo de calificación).

## More Information

- SRS: `docs/specs/srs001.md` §3.2 (REQ-FUNC-005).
- `GradingCard` es `"use client"`; `page.tsx` es RSC (pasa datos + strings).
- Si las etiquetas de criterios se comparten con tracker, consolidar bajo una
  clave `dashboard.scores` para evitar duplicación (REQ-REUSE-001).
