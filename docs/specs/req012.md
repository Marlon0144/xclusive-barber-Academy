# Compuertas de calidad trasversales (Definition of Done i18n)

## Statement

The system shall satisfacer, en **todos** los incrementos de traducción
(REQ-003…REQ-011), las siguientes compuertas de calidad: rendimiento sin
regresión de bundle, lecturas paralelas/cacheadas, seguridad de la cookie de
idioma, accesibilidad (`lang` + `aria`), observabilidad de cobertura, build
estricto, documentación viva y trazabilidad; y el contenido generado/HTML se
mantendrá sin traducir automáticamente en este incremento.

## Rationale

Los requisitos trasversales garantizan que la localización no degrade la
performance ni la seguridad del sistema (reglas Vercel Best Practices y
directivas de AGENTS.md) y que el trabajo quede documentado y verificable.

## Acceptance Criteria

Rendimiento:

- [ ] REQ-PERF-001: `progreso_profesional` permanece como RSC puro (0 JS de
      componente); ningún cambio añade JavaScript de cliente innecesario a rutas RSC.
- [ ] REQ-PERF-002: lecturas con columnas `_en` usan `Promise.all` y
      `React.cache`; sin `await` secuencial innecesario.

Seguridad:

- [ ] REQ-SEC-002: cookie `preferred_language` mantiene `sameSite: 'lax'`,
      `secure` en producción; valor validado contra `SUPPORTED_LANGUAGES`.

Accesibilidad:

- [ ] REQ-COMP-001: `<html lang>` refleja el idioma activo; `aria-label`/`alt`
      traducidos; conmutador con `role="group"` y `aria-label` localizado.

Observabilidad:

- [ ] REQ-OBS-001: existe un medio (regla de lint o script) para detectar
      cadenas en español hardcodeadas en `app/`/`components/` (ver REQ-MAINT-002).

Build:

- [ ] REQ-BUILD-001: `tsc --noEmit` y `next build` pasan sin errores.

Documentación:

- [ ] REQ-MAINT-001: se actualizan `docs/ARCHITECTURE.md` (subsistema i18n),
      `docs/COMPONENTS.md`, `docs/DATABASE.md` (columnas `_en`), `docs/ROUTES.md`
      (si cambian dependencias de datos) y `.ai/PROJECT_CONTEXT.md`.

Contenido no traducible (fuera de alcance, diferido):

- [ ] REQ-ML-001: `lessons.content` (HTML), `submissions.feedback_ai`,
      `submissions.cut_type`/`description` NO se traducen automáticamente.

## Verification Method

Analysis + Test + Inspection (cada compuerta con su método; ver columna de la
matriz en SRS §4).
