# Traducción de UI — Tracker (Seguimiento y Evaluación)

## Statement

The system shall renderizar todos los textos de la sección tracker
(`app/dashboard/tracker/page.tsx`, `SubmissionForm.tsx`, `SubmissionCard.tsx`,
`FeedbackModal.tsx`) desde el diccionario en el idioma activo, incluyendo
estados, etiquetas de formulario, placeholders, mensajes de error de validación
y botones.

## Rationale

El tracker es la funcionalidad de práctica del estudiante y está parcialmente
hardcodeado en español. Nota: los mensajes de error de la Server Action ya usan
`dictionary.actions.tracker`; este requisito cubre la **UI** y los errores de
validación del cliente.

## Acceptance Criteria

Cadenas → clave (namespace `dashboard.tracker`):

- [ ] `page.tsx`
      - `title="Evolución Profesional"` de `DashboardPageHeader` → `headerTitle`
      - `aria-label`/`alt` "Volver" → `back`
      - subtítulos/encabezados de sección ("ENVÍA TU PRÁCTICA…", "ENTREGA DE EVIDENCIA") → `sectionSubtitle` / `evidenceDelivery` (ajustar a los literales reales del archivo)
- [ ] `SubmissionForm.tsx`
      - "PRESENTAR PARA EVALUACIÓN" → `submit`
      - "Selecciona Tipo de Corte" (valor por defecto del selector) → `selectCutType`
      - placeholder "Describe brevemente el proceso realizado…" → `descriptionPlaceholder`
      - alt "Subir corte" → `uploadAlt`; alt "Preview" → `previewAlt`
      - Errores de validación del cliente → `validation.*`:
        - "El archivo está vacío" → `emptyFile`
        - "El archivo supera el límite de {n} MB" → `fileTooLarge` (interpolación)
        - "Tipo de archivo no permitido ({mime}). Solo imágenes." → `invalidMimeType`
        - "Extensión no permitida (.{ext}). Solo imágenes." → `invalidExtension`
        - "Error al subir la práctica" → `uploadError`
      - Opciones de `cut_type`: títulos técnicos ("Low Fade", "Mid Fade", "High Fade", "Taper Fade", "Buzz Cut") se consideran **invariantes/técnicos** (no se traducen); "Corte a Tijera" → `cutType.scissorCut` ("Scissor Cut").
- [ ] `SubmissionCard.tsx`
      - "PRÁCTICA {n}" (interpolación) → `practiceNumber`
      - "EN PROCESO DE REVISIÓN" → `status.pending`
      - "RETROALIMENTACIÓN" → `status.reviewed`
      - `aria-label` "Eliminar práctica" → `deletePractice`
      - alt "Práctica {n} – {cut_type}" → `practiceAlt` (interpolación)
- [ ] `FeedbackModal.tsx`
      - "Sin retroalimentación disponible." → `noFeedback`
      - Etiquetas de scores: "Fade / Desvanecido", "Limpieza", "Técnica", "Simetría" → `scores.fade / cleanliness / technique / symmetry`

- [ ] El feedback de IA (`submission.feedback_ai`) y la descripción del estudiante
      (`submission.description`) permanecen sin traducir (contenido de usuario/IA; fuera de alcance).

## Verification Method

Inspection (inventario) + Test (ES/EN, flujo subir/eliminar/ver feedback).

## More Information

- SRS: `docs/specs/srs001.md` §3.2 (REQ-FUNC-004).
- `SubmissionForm`, `SubmissionCard`, `FeedbackModal` son `"use client"`; leen
  el idioma vía `useLanguage()` o reciben cadenas por props desde la página RSC.
- Mensajes de error de la Server Action existentes (`dictionary.actions.tracker`)
  ya están traducidos en el diccionario; NO duplicar — reutilizar.
