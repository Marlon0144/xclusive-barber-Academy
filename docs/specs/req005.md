# Traducción de UI — Reproductor de Lección (`[courseId]/[lessonId]`)

## Statement

The system shall renderizar todos los textos fijos del reproductor de lección
(`app/dashboard/courses/[courseId]/[lessonId]/page.tsx`, `components/courses/
CourseSidebar.tsx`, `components/courses/VideoPlayer.tsx`) desde el diccionario
en el idioma activo, resolviendo el título/descripción del módulo y el título de
la lección a partir de las columnas `_en` con fallback al español.

## Rationale

La página de lección es la superficie de consumo de contenido más importante del
estudiante y contiene numerosos textos fijos en español ("LECCIONES", "MÓDULO n",
"SIGUIENTE LECCIÓN", etc.) que no responden al cambio de idioma.

## Acceptance Criteria

Cadenas fijas → clave (namespace `dashboard.lesson`):

- [ ] `page.tsx`
      - `title="LECCIONES"` de `DashboardPageHeader` → `lessons`
      - "MÓDULO {n}" (interpolación) → `moduleLabel`
      - "Bases esenciales de técnica, herramientas y precisión profesional." (default de módulo) → `moduleDefaultDescription`
      - "Micro texto Opcional" → `microOptional`
      - "Unidad Audiovisual" → `audiovisualUnit`
      - "Sin descripción disponible." (fallback sin `lesson.content`) → `noDescription`
      - "Referencias Visuales" → `visualReferences`
      - "SIGUIENTE LECCIÓN" → `nextLesson`; "LECCIÓN ANTERIOR" → `previousLesson`
      - "Fin del módulo" → `endOfModule`
      - alt "Volver" (back-row) → `back`
- [ ] `components/courses/CourseSidebar.tsx`
      - "Cargando..." → `loading`
      - "Volver a Cursos" → `backToCourses`
      - "Contenido del Módulo" → `moduleContent`
      - "Tu progreso" → `yourProgress`
- [ ] `components/courses/VideoPlayer.tsx`
      - "URL de video no válida" → `invalidVideoUrl`
      - "Video no disponible" → `videoUnavailable`
      - "✓ Lección Completada" → `lessonCompleted`
- [ ] `components/courses/LessonContent.tsx` no tiene texto fijo visible (renderiza
      `lesson.content`); no requiere cambios, confirmar en inspección.

Contenido de BD:

- [ ] Título de módulo (`moduleData.title`) se resuelve con `pick` usando `title_en`.
- [ ] Título de lección (`lesson.title`) se resuelve con `pick` usando `title_en`.
- [ ] El contenido HTML (`lesson.content`) permanece en español (fuera de alcance;
      ver REQ-012/REQ-ML-001).

## Verification Method

Inspection (inventario) + Test (ES/EN + lección con/sin `title_en`).
