# Migración de base de datos — columnas traducidas `*_en`

## Statement

The system shall disponer de una migración SQL idempotente que agregue a la
tabla `modules` las columnas `title_en` y `description_en`, y a la tabla
`lessons` la columna `title_en` (todas `text`, NULLables), sin alterar las
columnas existentes ni las políticas RLS.

## Rationale

Los títulos/descripciones de módulos y lecciones están almacenados solo en
español. Las columnas `*_en` habilitan la variante inglesa con fallback al
español (REQ-002). La idempotencia permite aplicar/re-aplicar sin errores.

## Acceptance Criteria

- [ ] Existe `scripts/2026-11-16-i18n-content-titles.sql` con:
      ```sql
      ALTER TABLE IF EXISTS public.modules
        ADD COLUMN IF NOT EXISTS title_en text,
        ADD COLUMN IF NOT EXISTS description_en text;

      ALTER TABLE IF EXISTS public.lessons
        ADD COLUMN IF NOT EXISTS title_en text;
      ```
- [ ] Las columnas son `NULL` (permiten fallback sin migrar datos de filas existentes).
- [ ] No se modifica `lessons.content` (HTML) — queda fuera de alcance.
- [ ] Validación previa del esquema real de `modules`/`lessons` (ver More Information).
- [ ] La aplicación de la migración no pierde datos ni rompe RLS existente.

## Verification Method

Analysis (revisión del DDL) + Demonstration (aplicar en Supabase y verificar `\d modules`, `\d lessons`).
