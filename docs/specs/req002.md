# Helper de localización con fallback es/en para columnas `*_en`

## Statement

The system shall proporcionar un único helper reutilizable en `lib/i18n/` que,
dado el idioma activo y un par `{ es, en }`, devuelva la traducción al inglés
cuando `language === 'en'` y el valor `en` exista (no `null`, no `''`), y el
valor en español en cualquier otro caso (incluido `language === 'en'` con
`en` vacío). Este helper shall ser la única implementación de fallback para
títulos/descripciones traducidos.

## Rationale

Las columnas `*_en` de la BD son NULLables (REQ-FUNC-007/008); si no existiera
una regla única de fallback, cada componente duplicaría `title_en ?? title` con
variantes inconsistentes. Centralizarlo evita bugs de render vacío y facilita el
mantenimiento (REQ-REUSE-001, REQ-REL-001).

## Acceptance Criteria

- [ ] Existe una función, p. ej.
      `pick(language: Language, values: { es: string | null; en: string | null }): string`
      en `lib/i18n/` (o `resolveLocalized(...)` con firma equivalente).
- [ ] Con `language='en'` y `en='Fade Fundamentals'`, devuelve `'Fade Fundamentals'`.
- [ ] Con `language='en'` y `en=null` o `en=''`, devuelve `es`.
- [ ] Con `language='es'`, devuelve `es` siempre.
- [ ] No existe lógica `title_en ?? title` duplicada en los componentes; todos
      llaman al helper.

## Verification Method

Test (unit) + Inspection (sin duplicación de lógica).

## More Information

- SRS: `docs/specs/srs001.md` §3.1.3 (REQ-INT-003), §3.3.3 (REQ-REL-001),
  §3.5.5 (REQ-REUSE-001).
- Se aplica a lecturas de `modules.title/description` y `lessons.title`.
- Los `select` de `utils/cache-helpers.ts` y de las páginas deberán incluir las
  columnas `title_en`/`description_en` para alimentar este helper.
