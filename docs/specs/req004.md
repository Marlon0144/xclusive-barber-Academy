# Traducción de UI — Lista de Cursos (`/dashboard/courses`)

## Statement

The system shall renderizar todos los textos de la lista de cursos
(`components/dashboard/courses/CourseListView.tsx` y
`app/dashboard/courses/page.tsx`) desde el diccionario en el idioma activo,
incluida la resolución por idioma del título/descripción de cada módulo a partir
de las columnas `title_en`/`description_en` con fallback al español.

## Rationale

El listado de módulos es la puerta de entrada al contenido académico y contiene
texto fijo + contenido de BD en español hardcodeado; no cambia al conmutar idioma.

## Acceptance Criteria

Cadenas fijas → clave (namespace `dashboard.coursesList`):

- [ ] "PROGRAMA DE FORMACIÓN" → `heading`
- [ ] "Estructura oficial del proceso académico alineado a estándares profesionales del mercado australiano." → `subtitle`
- [ ] "FORMACIÓN PROFESIONAL EN BARBERÍA" (subtítulo del banner) → `bannerSubtitle`
- [ ] "MÓDULO {n}" (interpolación) → `moduleLabel` (usar helper `interpolate` existente)
- [ ] "ESTADO:" → `statusLabel`
- [ ] "En progreso" → `inProgress`; "Bloqueado" → `locked`
- [ ] Fallback "Contenido esencial para tu formación." → `defaultDescription`
- [ ] Estado vacío "No hay módulos disponibles aún." → `empty`
- [ ] CTA "PONER EN PRÁCTICA MI FORMACIÓN" → `cta`

Contenido de BD:

- [ ] `module.title`/`module.description` se resuelven con el helper `pick`
      (REQ-002) usando `title_en`/`description_en`; el fallback
      `defaultDescription` solo aplica cuando la descripción resuelta es nula.

- [ ] `app/dashboard/courses/page.tsx` pasa `title="Módulos"` → localizado
      (`coursesList.headerTitle`: "Módulos"/"Modules") a `DashboardPageHeader`.

Fuera de alcance (avisar): los textos embebidos como **imagen SVG/PNG**
(`/assets/nombre-del-curso-text-resource.svg` y similares) NO se traducen vía
diccionario; requieren assets nuevos (diferido, no bloqueante).

## Verification Method

Inspection (inventario) + Test (ES/EN + módulo con/sin `title_en`).

## More Information

- SRS: `docs/specs/srs001.md` §3.2 (REQ-FUNC-002).
- `CourseListView` es `"use client"`; recibe `modules` con las columnas `_en` ya
  seleccionadas desde la página RSC padre (`app/dashboard/courses/page.tsx`) o
  lee el idioma vía `useLanguage()`.
- Dependencia: REQ-009 (columnas `_en`) para el punto de contenido de BD.
