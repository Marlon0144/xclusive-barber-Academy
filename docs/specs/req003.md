# Traducción de UI — Dashboard Hub (`/dashboard`)

## Statement

The system shall renderizar todos los textos de la página `/dashboard` y sus
subcomponentes (`DashboardHeader`, `DashboardCard`, `AdminToolsMenu`,
`DashboardFooter`) desde el diccionario en el idioma activo, eliminando todo
texto en español hardcodeado.

## Rationale

Es la pantalla principal del estudiante y está 100% hardcodeada en español; es
la primera superficie visible al entrar a la app y hoy no responde al cambio de
idioma (problema reportado).

## Acceptance Criteria

Cadenas actuales → clave de diccionario (namespace `dashboard`):

- [ ] `components/dashboard/DashboardHeader.tsx`
      - "Tu proceso de formación comienza aquí" → `hero.tagline`
      - "Área Académica" → `hero.title`
      - "Espacio oficial de formación y seguimiento profesional dentro de la academia." → `hero.description`
- [ ] `app/dashboard/page.tsx` (tarjetas del hub, vía props a `DashboardCard`)
      - "Programa de Formación" → `hub.trainingProgram.title`; su descripción → `hub.trainingProgram.description`
      - "Seguimiento y Evaluación" → `hub.tracking.title`; descripción → `hub.tracking.description`
      - "Progreso Profesional" → `hub.progress.title`; descripción → `hub.progress.description`
      - "La Academia" → `hub.academy.title`; descripción → `hub.academy.description`
- [ ] `components/dashboard/AdminToolsMenu.tsx`
      - "Panel de Gestión" → `adminMenu.panelLabel`
      - "Evaluar Estudiantes" + descripción → `adminMenu.gradeStudents.title/.description`
      - "Gestión de Cursos" + descripción → `adminMenu.manageCourses.title/.description`
      - "Gestión de Usuarios" + descripción → `adminMenu.manageUsers.title/.description`
      - "Gestión de Leads" + descripción → `adminMenu.manageLeads.title/.description`
- [ ] `components/dashboard/DashboardFooter.tsx`
      - tagline por defecto "Plataforma oficial de desarrollo académico." → `footer.tagline`
      - `aria-label` "Abrir Instagram de Xclusive Barber Academy" → `footer.instagramAria`
      - `aria-label` "Abrir chat de WhatsApp con el equipo de Xclusive" → `footer.whatsappAria`
- [ ] `components/dashboard/DashboardCard.tsx`: badges "Admin"/"Instructor" se
      consideran invariantes (no requieren traducción); se documenta como excepción.

- [ ] Con `language='en'`, ninguna cadena visible de `/dashboard` aparece en español.

## Verification Method

Inspection (inventario arriba) + Test (cambio de idioma manual ES/EN).

## More Information

- SRS: `docs/specs/srs001.md` §3.2 (REQ-FUNC-001).
- Patrón de implementación: páginas RSC leen `const dict = await
  getServerDictionary()`; `DashboardCard`/`AdminToolsMenu` reciben las cadenas
  por props (o usan `useLanguage()` si son client). Ver 5.E de la SRS.
- `DashboardHeader` y `DashboardFooter` son RSC; `AdminToolsMenu` es `"use client"`.
